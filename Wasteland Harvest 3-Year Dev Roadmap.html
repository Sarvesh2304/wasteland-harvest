WASTELAND HARVEST

A post-apocalyptic farming & survival RPG inspired by Stardew Valley.
Full 3-year development roadmap — from first line of code to launch-ready build.
Godot 4 Pixel Art Top-Down RPG Post-Apocalyptic Farming Sim Expedition Combat NPC Systems Auto-Save Co-Op Expeditions
Year 1 — Foundation Year 2 — Content Year 3 — Expansion & Launch System Map
⚙

Recommended Engine: Godot 4

Free, open-source, and purpose-built for 2D pixel-art games. GDScript is Python-like and easy to learn. Has built-in tilemaps, scene trees, lighting, and animation tools — ideal for a Stardew-style top-down RPG. Start at godotengine.org. Use Git (GitHub/GitLab) for version control from day one.

Year 1 — Foundation & Prototype

MONTHS 01 – 12
Goal: A playable vertical slice — one map, one farming loop, one NPC, auto-save working.
01
MONTHS 01–02
Setup, Design & World Building
GDD + Engine
  • Write your Game Design Document (GDD) — core loop, world lore (what caused the apocalypse?), player goals, win/lose conditions, tone and art direction.
  • Define your map layout — sketch 3 starting settlement types (forest edge, riverside, open plains), town layout (mayor's house, store, water body), and ruined city concept.
  • Set up Godot 4 — install engine, create project structure, set up Git version control with GitHub. Commit every session.
  • Establish your pixel art style — choose tile size (16×16 or 32×32 px), define colour palette (post-apoc dusty ambers, faded greens), and create your first test tiles.
  • Install Aseprite (pixel art tool) and begin drawing basic tiles: soil, grass, ruin rubble, wood planks.
MONTHS 03–04
Core Engine — Player, World & Day/Night Cycle
Engine Core
  • Player character — 4-directional movement, walking animation (idle, walk, tool-use). Use Godot's CharacterBody2D.
  • Tile-based world — implement Godot's TileMap node. Build a small test map (farmland + surrounding area). Add collision layers.
  • Camera system — smooth follow camera that clamps to map boundaries. Add screen shake for future combat.
  • Day/Night cycle — a global DayManager node tracks time (e.g., 1 in-game minute = 1 real second). Sky colour shifts from dawn → noon → dusk → night using a CanvasModulate node. Day counter displayed in HUD.
  • Basic HUD — day number, in-game clock, energy bar. Post-apoc UI aesthetic (scavenged metal, cracked glass).
Day/night cycle fully functional. Player can walk around a test map and time passes visually.
MONTHS 05–06
Farming Core & Inventory System
Gameplay Loop

Farming Mechanics

  • Till soil with a hoe (converts normal ground tile to farmable tile)
  • Plant seeds (click to place seed item on tilled tile)
  • Water crops daily or they die. Visual indicator if watered.
  • Growth stages — 4–6 visual stages per crop. Crops auto-progress each morning. Post-apoc themed crops: Mutant Potato, Dustwheat, Ironroot, Sunbloom.
  • Harvest — interact with mature crop to collect produce.

Inventory & Tools

  • Inventory grid — slot-based with item stacking. Hotbar for quick access.
  • Tool system — Hoe, Watering Can, Axe, Pickaxe, Bag. Each has durability (upgradeable later).
  • Energy system — each action costs energy. Pass out if energy hits zero (lose the rest of the day).
  • Item data — define your first 20 items (seeds, crops, wood, stone, scrap metal, food).
Full farming loop functional: till → plant → water → grow → harvest → inventory.
MONTHS 07–08
Settlement Maps, Building & Auto-Save
World + Save System
  • Settlement selection screen — at game start, player chooses from 3 starting maps. Each has a different starting layout, terrain, and small lore blurb. Maps differ in starting resources (one has water access, one has more ruin materials, one has better soil).
  • Full farmland map — hand-crafted tile map for the player's home area. Includes: farm plots, derelict home structure, storage chest, a small perimeter fence gap (for player to close later).
  • Town map rough draft — connected map with: mayor's fortified house, one trading store, 3–4 settler shacks, water body (river or lake) with dock, bulletin board.
  • Basic building placement — player places a structure blueprint, spends resources, waits 1 in-game day. Implement as a simple grid-snap system.
  • Auto-save at end of day — when the player goes to sleep (interact with bed), game saves all state: crops, inventory, day, world modifications. Show a brief "WORLD SAVED" notification. Use Godot's FileAccess + JSON serialisation.
Auto-save works. Player can quit and reload mid-playthrough with all state restored.
MONTHS 09–10
Basic NPCs, Town Economy & Dialogue
NPCs + Economy
  • NPC base class — NPCs have a name, sprite, position, and dialogue data. They wander within a defined zone. Use Godot's NavigationAgent2D for pathfinding.
  • Dialogue system — press interact near an NPC to open a dialogue box. Text prints character by character. Basic branching (choose a response). Store dialogue in JSON files for easy editing.
  • First NPCs: Mayor Harlan (quest-giver, gives objectives), Marta (store owner), Scout Kael (tells you about the ruined city).
  • Town store — Marta sells seeds, basic tools, food. UI shows item name, description, price. Player buys with Scrap Coins (your currency).
  • Shipping box — player places harvested crops in a shipping crate before sleeping. Next morning, Scrap Coins are added to wallet. Tracks sale history.
Player can farm, sell crops, earn currency, and buy seeds. Economy loop is closed.
MONTHS 11–12
First Playable Build & Stabilisation
Integration + QA
  • Integrate all Year 1 systems — ensure farming, inventory, economy, NPCs, day/night, auto-save all work together without conflicts.
  • Bug fixing sprint — play through 5 in-game days end to end. Fix crashes, edge cases, broken tile interactions.
  • Internal playtesting — get 3–5 people to play it. Note what's confusing, what breaks, what feels fun. Prioritise fixes for Year 2.
  • Art pass 1 — replace placeholder tiles with proper pixel art. At least: ground tiles, farmland, player character, 3 NPCs, basic buildings.
  • First demo build — export a Windows build. You now have a shareable prototype.
… END OF YEAR 1: Vertical slice demo complete. Full farming loop, one town, 3 NPCs, auto-save, day/night cycle working.

Year 2 — Systems & Content Build-Out

MONTHS 13 – 24
Goal: All major game systems implemented. Expedition combat, full NPC personalities, building/settlement, seasons.
02
MONTHS 13–14
Advanced NPC System — Personalities, Schedules & Relationships
NPC Depth
  • NPC personality system — each NPC gets a personality tag that shapes their dialogue and behaviour: Paranoid Survivor, Optimistic Builder, Gruff Soldier, Gentle Medic, Secretive Scavenger, Pragmatic Trader.
  • Daily schedules — each NPC follows a schedule: wakes up, does tasks (tending garden, working in store, walking to water), eats, sleeps. Location changes by time of day. Feels like a living town.
  • Relationship/affinity system — each NPC has a 0–10 affinity with the player. Increases by: talking daily, gifting preferred items, completing quests. Decreases by: gifting disliked items, ignoring them for many days. Affinity gates new dialogue and story events.
  • Gift preference database — each NPC has liked, loved, neutral, and hated items. "Scout Kael loves scavenged ammo. Marta loves seeds. Mayor Harlan loves Ironroot stew."
  • Context-sensitive dialogue — NPCs comment on the weather, time of day, the player's affinity level, recent world events. Stored in expandable JSON trees.
Town feels alive. NPCs move around, have schedules, react to you based on your relationship with them.
MONTHS 15–16
Building, Settlement Expansion & Fencing System
Construction
  • Building type library — implement 12+ buildable structures: Shelter Cabin, Storage Barn, Workshop, Clinic, Trading Post, Watchtower, Greenhouse, Compost Pit, Rain Collector, Solar Panel, Antenna Tower, Community Kitchen.
  • Building grid system — snap-to-grid placement with visual preview (green = valid, red = blocked). Resource cost displayed before placing. Construction time (1–3 days depending on building size).
  • Fencing & perimeter system — player can place fence segments, wooden walls, reinforced gates around the entire settlement boundary. Different materials: wood fence, chain-link, concrete wall. Each has different durability (relevant for future raid events).
  • Settler system — every few in-game weeks, a new Survivor NPC appears at the settlement edge asking to join. Player can accept or reject. Accepted settlers move in, add to the town population, and unlock new dialogue/economy options.
  • NPC–building assignment — assign a settler to a building (e.g., assign Medic Petra to the Clinic). That building then produces a passive benefit (healing, goods) or becomes a functioning in-game shop.
MONTHS 17–18
Expedition System — Ruined City & Combat
Combat + Exploration
  • Ruined city map(s) — build 2–3 distinct ruined city zones: Downtown Ruins (tall rubble, shops), Industrial Quarter (factories, vehicles), Residential Blocks (houses, gardens). Hand-crafted tile maps with hidden areas and loot spawns.
  • Solo expedition mode — player packs a backpack (limited expedition inventory), travels to a city zone. Return happens automatically at a set time (or sooner if the player chooses). Stamina counts down during expeditions.
  • Zombie & monster AI — enemies patrol set routes. On detecting the player (line-of-sight cone), they chase. Combat states: Idle → Alerted → Chasing → Attacking. Use Godot's NavigationAgent2D for chase pathfinding.
  • Combat system — basic melee (swing range, knockback, hit flash) and ranged (thrown objects, scavenged crossbow). Player has HP. Death during expedition = lose expedition loot, respawn at settlement with 10% HP. Roguelike penalty encourages preparation.
  • Loot system — destructible crates, abandoned cars, and ruined buildings contain randomised loot from a weighted table: scrap, food, seeds, medicine, tools, rare blueprint scrolls, ammo. Blueprint scrolls unlock new buildings/recipes.
  • Settlement is a safe zone — zombies cannot enter the settlement boundary. Player always has a guaranteed safe home base.
Expeditions feel risky and rewarding. Player must prepare before going, and brings back supplies that improve the town.
MONTHS 19–20
Business System, Crafting & Advanced Economy
Economy Depth
  • Crafting system — Workshop lets player craft items: Scrap Tools, Preserved Food, Medicine, Ammunition, Building Materials. Recipes are unlocked via Blueprint Scrolls found on expeditions.
  • Player-run businesses — once you build a Trading Post, players can set their own item sell prices and stock items from their inventory. Passing Caravan NPCs (new NPC type) visit weekly and buy from your post.
  • Settler economy — settlers assigned to businesses generate passive income/goods daily. E.g., a settler assigned to the Greenhouse produces 2 random crops per day.
  • Caravan traders — weekly visiting NPCs with a rotating stock of rare goods. Player can sell to caravans or buy from them. Caravans react to town affinity (higher affinity = better prices, rarer stock).
  • Supply & demand — item prices in Marta's store fluctuate based on what was recently sold. Selling 20 Dustwheat makes Dustwheat worth less. Adds strategic depth to farming choices.
MONTHS 21–22
Seasons, Weather & World Events
World Systems
  • 4-season cycle (28 in-game days each): Spring Rains, Scorched Summer, Amber Autumn, Grey Winter. Each season changes which crops grow, what's on sale, and the lighting palette.
  • Seasonal crops — 4–6 unique crops per season. Winter has no outdoor farming (player must use Greenhouse). Encourages planning ahead and stockpiling.
  • Weather system — daily weather rolls: clear, cloudy, rain (waters crops automatically), heavy storm (stay indoors), rare radstorm (don't go outside). Weather shown as a forecast icon in HUD.
  • World events — scripted events that trigger on certain days: Bandit Scout spotted near perimeter (fencing matters here), Trader Caravan arrives with rare stock, Survivor arrives seeking shelter, Disease outbreak in town (Clinic needed), Mysterious Signal on the radio (story hook).
  • Town festivals — seasonal community events (Harvest Day, Winter Gathering) that boost all NPC affinity and have mini-game activities (cooking contest, best crop competition).
MONTHS 23–24
Full Map Polish, Fishing & Beta Testing
Beta + QA
  • 3 fully built starting maps — complete all 3 settlement starting options with full tile art, unique lore notes, and distinct early-game advantages.
  • Water body + fishing — river/lake with animated water tiles. Cast a line (minigame: wait for bite, tap at right moment). Fish become a food and trade commodity. Some rare fish trigger NPC dialogue.
  • Full town map — mayor's fortified house, Marta's store, Clinic, Watchtower, Community Board (shows town objectives), 6–10 settler homes, dock on water body, market stalls.
  • Beta testing — release a closed beta to 10–20 testers. Collect feedback on balance, clarity, fun. Fix critical issues before Year 3.
  • Performance audit — ensure game runs at 60fps on modest hardware. Optimise tile rendering, NPC pathfinding, save/load times.
… END OF YEAR 2: All core systems built. Full game loop from farming → expeditions → building → economy → seasons. Beta tested.

Year 3 — Story, Expansion & Launch

MONTHS 25 – 36
Goal: Full story, expanded world, co-op expeditions, full audio/visual polish, and public launch.
03
MONTHS 25–26
Story, Narrative & Quest System
Story
  • Main story arc — write a full narrative: the player arrived at this settlement for a reason. Over the course of in-game years, they uncover what caused the apocalypse (experiments? war? disease?), and face a decision: rebuild civilisation, or push further into the wasteland. No single ending — player choices matter.
  • NPC personal questlines — each of the 8–10 main NPCs has a 3–5 quest chain that reveals their backstory and resolves a personal struggle. Mayor Harlan is hiding something about the pre-war town. Scout Kael is searching for a missing sibling in the ruins. Marta is hoarding medicine for a reason.
  • Quest journal — clean UI showing active/completed quests with objectives, NPC portrait, and a lore snippet. Quests tracked per NPC and per main story chapter.
  • Story moments & cutscenes — key story beats trigger short pixel-art animated sequences (2–5 second scenes with panning tiles and text overlays). Used sparingly for high-impact moments.
  • Lore layer — scatter handwritten notes, radio broadcasts, and worn posters throughout the world. These drip-feed the backstory without forcing it on the player.
MONTHS 27–28
Expanded World — Nearby Cities & New Zones
World Expansion
  • World map screen — a stylised hand-drawn map showing your settlement, 3 ruined city zones, 2 new major city areas (locked until mid-game), and points of interest. Fast-travel unlocked by finding Radio Tower components.
  • 2 new major city zones — "The Vault District" (pre-war government buildings, high danger, high reward) and "The Boneyard Markets" (an NPC-run trading hub in the ruins, semi-safe, introduces new merchant NPCs).
  • Underground/bunker areas — hidden entrances in existing maps lead to bunker levels. Darker, claustrophobic tile aesthetic, more difficult enemies, unique loot (pre-war technology, research notes).
  • New monster variety — add 5 new enemy types: Mutant Hound, Armoured Zombie, Feral Scavenger (human NPC turned hostile), Acid Spitter, and a rare Boss Behemoth that guards a major loot cache.
  • Rare / legendary items — 15 unique named items found only in endgame zones. E.g., "Harlan's Old Rifle," "Pre-War Medical Scanner," "The Settler's Almanac."
MONTHS 29–30
Team Expeditions & Co-Op System
Multiplayer
  • Co-op expedition framework — 2–4 players can join an expedition together via online lobby (Godot's built-in networking or Steam multiplayer). The host's world is shared; guests join for the expedition only.
  • Party formation UI — before leaving, party members can see each other's loadouts, agree on a destination zone, and set a return timer.
  • Co-op combat scaling — enemy count and HP scale with party size. Larger parties get harder expeditions but proportionally more loot.
  • Shared loot distribution — at expedition end, a loot split screen shows total haul. Each player picks items in a round-robin draft order. Prevents disputes.
  • NPC companion expeditions — if co-op isn't possible solo, player can take 1–2 settler NPCs on expeditions instead. NPCs fight at reduced effectiveness but provide company and carry extra loot.
MONTHS 31–32
Audio, Visual Polish & Accessibility
Polish
  • Full pixel art pass — redraw all tiles, characters, items, and UI elements with consistent style. Animate: water, fire, crops swaying, NPC blinking, tool swings.
  • Sound design — ambient soundscapes per zone: wind across ruined concrete, distant shuffling in the city, crickets at night on the farm, rain on a tin roof. Each action has a distinct sound (hoe tilling, watering can pour, wood chopping).
  • Original soundtrack — compose or commission 10–15 tracks. Style: chiptune meets post-apoc ambient. Farm area: calm acoustic chip. City zones: tense, arrhythmic. Town: warm community chip. Boss encounter: driving percussion.
  • UI/UX redesign pass — full UI theme: worn paper textures, scavenged metal frames, hand-drawn icons. Consistent font. Satisfying click/hover sounds on UI elements.
  • Accessibility options — adjustable text size, colourblind mode, reduced motion toggle, subtitles for all NPC dialogue, remappable controls.
MONTHS 33–34
Balance, Content Completion & Achievements
Content Lock
  • Economy balancing — price every item, tune the earning curve so the first year feels tight but by year 3 in-game the player feels established. Run 5 full playthroughs specifically checking the economy.
  • Complete item database — target 120+ unique items: seeds, crops, processed foods, building materials, weapons, medicine, lore items, furniture, decorative objects.
  • All NPC dialogue finalised — every main NPC has 30+ unique dialogue lines, 3–5 quest stages complete, seasonal comments, and affinity-dependent responses.
  • Achievement system — 40 achievements covering: farming milestones ("Grew 500 crops"), social milestones ("Max affinity with 5 NPCs"), exploration ("Cleared all city zones"), survival ("Survived 3 full years"), and hidden achievements for story moments.
  • Options menu — save slots (3), volume controls, resolution options, fullscreen toggle, control rebinding.
MONTHS 35–36
QA, Launch Preparation & Release
Launch
  • Full QA bug sweep — systematic testing of every system interaction. Focus on: save/load edge cases, NPC schedule conflicts, expedition loot exploits, building placement bugs, multiplayer desyncs.
  • Performance optimisation — target stable 60fps on a 5-year-old mid-range PC. Profile CPU/GPU usage. Optimise NPC pathfinding (limit update frequency), tile rendering, and particle effects.
  • Platform export — primary target: Windows PC (Steam & itch.io). Stretch goals: macOS, Linux. Console ports (if relevant) require separate certification processes — plan for 6 months after PC launch.
  • Store page & marketing — Steam page with screenshots, a 90-second gameplay trailer, and a clear store description. Post devlogs on itch.io, Reddit (r/indiegaming, r/gamedev), and a community Discord.
  • Press & content creator outreach — send keys to 20–30 gaming content creators and indie game journalists 2 weeks before launch. Stardew Valley fans are your primary audience.
  • Launch day — monitor crash reports, respond to reviews, hotfix critical bugs within 24 hours. Prepare a Day 1 patch based on beta feedback.
… END OF YEAR 3: Full game shipped. Post-apoc farming RPG live on Steam/itch.io with all systems, story, co-op expeditions, and polish complete.
